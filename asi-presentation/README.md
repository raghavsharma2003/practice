# Event Horizon

An animated, presentable website on AI's path from GPT to superintelligence (as of Nov 2026).

- Open `index.html` in a browser (needs internet for Google Fonts).
- Present with arrow keys / space, `F` for fullscreen; the right rail jumps between chapters.
- `slides.html` is the same page without the document wrapper (used for publishing as an artifact).

Every claim carries a status badge; many late-2026 figures are very recent, so re-check them before presenting.
